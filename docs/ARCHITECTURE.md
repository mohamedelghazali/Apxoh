# Apxoh Architecture

Apxoh separates governance data, deterministic evaluation, evidence collection, integrations, and reporting. Manifests describe capabilities; rules and policies define requirements; the Python engine validates and evaluates them; evidence records the basis for decisions; integrations remain optional and cannot override deterministic decisions.
