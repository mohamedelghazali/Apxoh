## Documented External Blockers & Deliberate Deferrals

1. **External Proprietary `tsar` Binary (`SE-SEC-GOV-001`)**: `TsarRunner` invokes an external `tsar` binary when installed on `PATH`. Because `tsar` is not a public PyPI dependency, `SE-SEC-GOV-001` truthfully reports `BLOCKED` (`tsar executable not found on PATH`) when `tsar` is absent rather than fabricating a pass, preserving GENCODE-GOV's fail-closed evidence contract while `SE-SEC-GOV-002` (`SecurityAuditRunner`) and `SE-SEC-011` execute natively.
2. **SLSA Reusable Workflow Tag Pinning (`slsa-release.yml`)**: `slsa-framework/slsa-github-generator` mandates an exact `@vX.Y.Z` tag reference (`@v2.1.0`) rather than a commit SHA so `slsa-verifier` can validate the builder's OIDC `job_workflow_ref` claim. `SE-DEV-002` (`github-actions-sha-pinning-scan`) explicitly enforces 40-character commit SHAs on all other external actions while honoring this upstream SLSA specification requirement.
3. **Full Mutation-Testing Execution in Default `assess` Loop**: Running repository-wide AST mutation testing (`mutmut` / `cosmic-ray`) synchronously inside every `gencode-gov assess` invocation would add multi-minute latency per run; instead, `SE-TST-005` enforces fast deterministic AST assertion-adequacy and diff test-tampering checks synchronously, leaving full mutation campaigns as an optional CI stage.
