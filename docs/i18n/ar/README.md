# АРХОН (ARKHON)

> **الدليل قبل الاعتماد. التحقق قبل الإصدار.**

**АРХОН** هو **نظام حوكمة وضمان هندسة البرمجيات**.

وُضع للإجابة عن سؤال واحد بأدلة قابلة للتحقق، لا بمجرد الرأي:

> *هل هذه البرمجية جاهزة فعلاً للاعتماد عليها مع مستخدمين حقيقيين؟*

لا يكتفي АРХОН بما يعلنه وكيل الذكاء الاصطناعي عن اكتمال العمل؛ بل يطلب تحققاً مستقلاً قابلاً لإعادة التنفيذ، وفق قواعد هندسية معلنة.

---

## ثلاثة منتجات في مستودع واحد

| المنتج | الدور | طبيعة الاستخدام |
| :--- | :--- | :--- |
| **Apxoh Core** | محرك الحوكمة والتحقق | تشغيل محلي وواجهة سطر أوامر |
| **Apxoh Agent Governance** | تعليمات ومهارات لوكلاء البرمجة | إرشاد الوكلاء إلى قواعد المشروع |
| **Apxoh Assurance** | التحقق والأدلة وبوابات الإصدار | تقييم مدفوع بالأدلة |

وكيل الذكاء الاصطناعي قد يكتب البرنامج؛ **أما АРХОН فيوفّر إطاراً للتحقق منه**.

## ما ليس عليه АРХОН

- ليس مجرد مكتبة أوامر (prompts).
- ليس أداة Lint وحدها.
- ليس بديلاً عن الحكم الهندسي البشري.
- ليس شهادة اعتماد صادرة عن جهة معايير.

إنه إطار حوكمة وضمان يهدف إلى وصل تطوير البرمجيات بالتحقق والمراجعة قبل الإصدار.

## البدء السريع

يتطلب المشروع Python 3.11 أو أحدث. الأوامر التالية موجهة إلى بيئة Linux/macOS؛ في Windows استخدم تفعيل البيئة الافتراضية عبر `.venv\Scripts\Activate.ps1`.

```bash
git clone https://github.com/mohamedelghazali/Apxoh.git
cd Apxoh
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
arkhon version
arkhon validate
```

## المبادئ التأسيسية

1. لا يُقبل متطلب دون معيار تحقق واضح.
2. لا يُقبل كود دون مراجعة واختبارات مناسبة.
3. نجاح CI/CD وحده ليس دليلاً كافياً على جودة النظام.
4. لا يُعلن الأمن دون دليل أمني قابل للتحقق.
5. لا يُعلن الأداء دون قياسات تحت أحمال محددة.
6. لا تُعلن الاعتمادية دون اختبار الأعطال والاستعادة.
7. لا يُعتمد إصدار إنتاجي دون مراجعة جاهزية.
8. لا تُخفى المخاطر الحرجة أو الأدلة الناقصة.
9. لا يُجرى تغيير جوهري دون مراجعة أثره.
10. ينبغي توثيق نتائج الفحص والإصلاح بما يسمح بإعادة التحقق.
11. تستمر مراقبة الجودة والأمن والموثوقية بعد الإطلاق.
12. تُبنى قرارات الاعتماد على الأدلة لا على الادعاءات.

> **لا اعتماد دون دليل. لا إصدار دون تحقق. لا ثقة دون اختبار. لا ادعاء دون إثبات.**
