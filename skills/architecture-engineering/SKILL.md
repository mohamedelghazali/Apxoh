# architecture engineering

1. Read repository instructions and applicable policies.
2. Establish scope, assumptions, and acceptance criteria.
3. Identify applicable rules and evidence requirements.
4. Perform authorized work only.
5. Run available deterministic checks.
6. Report PASS, FAIL, BLOCKED, NOT_APPLICABLE, or ACCEPTED_RISK accurately.

Never invent evidence, bypass policy gates, or claim certification.
